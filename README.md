# OMNeT-Simulations

This repository contains four OMNeT++ simulation projects related to SDN-assisted WSN studies:

- SDNWSNTest_baseline_v1 (local routing)
- SDNWSNTest_baseline_SDN_routing_baseline_v2 (controller routing)
- SDNWSNTest_coding_everywhere
- SDNWSNTest_coding_controller_select

Each project contains a separate simulation scenario or routing/coding variant.
